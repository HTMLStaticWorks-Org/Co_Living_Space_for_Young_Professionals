Nestly Co-Living Website & Resident Portal Guide

Complete reference for customizing colors, typography, brand name, currency, images, and third-party integrations.

1. Quick Start & Installation

Zero Build Step Required

Nestly is built with pure semantic HTML5, CSS3 custom properties, and vanilla ES6+ JavaScript. Open index.html directly in any modern browser or serve the folder with any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, or Nginx).

2. Customizing Brand Palette & Fonts

Edit assets/css/style.css & assets/css/dark-mode.css

All colors are controlled via `:root` variables at the top of assets/css/style.css: --ink (#0F2B2A), --teal (#14746F), --clay (#E2674A), --saffron (#F5B84B), --sage (#BFD8C5), --cream (#FBF6EE), --sand (#F1E7D6), and --mist (#E9F1EE).
